# Luandi Servicios - Control de Ingreso y Entrega de Vehículos

Sistema web para registro y gestión de ingresos, servicios realizados y entrega de vehículos.

## Funcionalidades

- Registro de ingreso de vehículos con datos de empresa cliente
- Catálogo de servicios y equipamiento con checkboxes
- Captura de firma digital del cliente (ingreso y retiro)
- Historial con filtros por patente, empresa y estado
- Exportación a Excel (CSV)
- Generación de PDF imprimible
- Almacenamiento local en navegador
- Diseño responsive (PC, tablet, móvil)

## Tecnologías

- React 18
- Vite
- Tailwind CSS
- Lucide React (iconos)

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue

Conectado automáticamente a Vercel.
